# iFarmer পূর্ণাঙ্গ ওয়েবসাইট — স্টার্টার প্যাকেজ

এতে রয়েছে:
- বাংলা-প্রথম responsive ওয়েবসাইট
- পণ্য ক্যাটালগ ও অর্ডার অনুরোধ ফর্ম
- FastAPI ব্যাকএন্ড + SQLite ডেটাবেস
- সুপার অ্যাডমিন লগইন ও অর্ডার তালিকা
- পার্টনার দোকান/সাবডোমেইন অনুমোদন অনুরোধ
- অনুমোদন/বাতিলের জন্য মালিকের ড্যাশবোর্ড
- সাধারণ GME Agro ব্র্যান্ড-নাম নিষেধাজ্ঞার টেক্সট চেক
- অর্ডার ও পার্টনার অনুরোধের প্রাথমিক audit log

## চালানোর নিয়ম (কম্পিউটারে)

Python 3.10+ লাগবে।

1. ZIP Extract করুন।
2. এই ফোল্ডারে Terminal / Command Prompt খুলুন।
3. চালান:
   `python -m venv .venv`
4. Windows:
   `.venv\Scripts\activate`
   macOS/Linux:
   `source .venv/bin/activate`
5. চালান:
   `pip install -r requirements.txt`
6. `.env.example` কপি করে `.env` করুন এবং `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `SECRET_KEY` বদলান।
7. চালান:
   `uvicorn app:app --host 127.0.0.1 --port 8000`
8. ব্রাউজারে খুলুন:
   - ওয়েবসাইট: http://127.0.0.1:8000
   - মালিক ড্যাশবোর্ড: http://127.0.0.1:8000/admin

## নিরাপত্তা ও লাইভ ব্যবহারের আগে

এই প্যাকেজটি কাজ করার মতো MVP/স্টার্টার; এখনই production-ready হিসেবে ইন্টারনেটে প্রকাশ করবেন না। লাইভ চালুর আগে অবশ্যই:
- HTTPS এবং reverse proxy সেটআপ করুন
- শক্তিশালী `SECRET_KEY` ও অ্যাডমিন পাসওয়ার্ড ব্যবহার করুন
- `COOKIE_SECURE=true` করুন
- ডেটাবেস ব্যাকআপ, লগ মনিটরিং, rate limiting ও spam protection যোগ করুন
- privacy policy, terms, returns/delivery policy এবং যোগাযোগের তথ্য দিন
- পণ্যের আইনসম্মত বিক্রয়/লাইসেন্স এবং স্থানীয় বিধি যাচাই করুন
- SMS/ফোন কল, পেমেন্ট গেটওয়ে ও COD অপারেশনাল ইন্টিগ্রেশন আলাদাভাবে যুক্ত করুন
- পার্টনার সাবডোমেইন স্বয়ংক্রিয়ভাবে চালু করতে DNS ও hosting API সংযুক্ত করতে হবে

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- অর্ডার এখন SQLite-এ সেভ হয়, কিন্তু SMS/ফোন কল স্বয়ংক্রিয় হয় না।
- COD হলো অর্ডারের পছন্দ/অনুরোধ; এটি কোনো পেমেন্ট প্রসেসর নয়।
- পার্টনার সাইটের অনুরোধ অ্যাডমিন অনুমোদন করতে পারেন; অনুমোদন পেলেই DNS/সাইট স্বয়ংক্রিয়ভাবে তৈরি হয় না।
- সাধারণ টেক্সটে নিষিদ্ধ ব্র্যান্ডের কিছু বানান পরীক্ষা করা হয়; ছবি, লোগো, ফাইল বা সব Unicode variation শনাক্ত করার নিশ্চয়তা নেই।
- ডিফল্ট অ্যাডমিন পাসওয়ার্ড নেই। `.env`-এ সেট না করলে অ্যাডমিন লগইন কাজ করবে না।
